# Information Architecture

# Principles

Travel Companion never forces users to search for information.

The application proactively presents relevant content.

---

# Navigation

Dashboard

↓

Current Trip

↓

Timeline

↓

Object Cards

---

# Three Click Rule

Important information must be accessible within three interactions.

---

# Ten Second Rule

Critical travel information must be accessible within ten seconds.

---

# Dynamic Dashboard

Dashboard adapts to:

- Planning
- Ready
- Traveling
- Completed

---

# Current Context

Dashboard content depends on:

- Active Trip
- Trip State
- Current Time
- Timeline
- User Context

---

# Search

Global Search is always available.

Search returns:

- Trips
- Locations
- Documents
- Equipment
- Knowledge
- Expenses

---

# Object Cards

Every object has one dedicated card.

Cards replace traditional forms.

---

# Context Navigation

Navigation adapts to the current object.

Users never navigate through deep menu structures.

---

# UX Philosophy

Show less.

Show better.

Show at the right moment.
